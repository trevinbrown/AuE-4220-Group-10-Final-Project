# Individual report outlines from the supplied templates

The ZIP contains two *recommended* Word templates. The individual report must describe achievements/findings for **both** projects. The handout does not explicitly clarify whether to hand in one combined document or separate Project 1/2 documents, so verify submission mechanics.

## Project 1 Report: Sensing Signal Processing

1. **Signal Processing for One Ultrasonic Sensor**
   - 1.1 Problem Statement
   - 1.2 Technical Approach
   - 1.3 Hardware and Software Implementation
   - 1.4 Experimental Results
2. **Sensor Fusion of Multiple Ultrasonic Sensors**
   - 2.1 Problem Statement
   - 2.2 Technical Approach
   - 2.3 Hardware and Software Implementation
   - 2.4 Experimental Results
3. **Conclusions and Discussions**
   - 3.1 Conclusions (summary of different approaches' results)
   - 3.2 Discussions (comparison of approaches and potential improvements)

## Project 2 Report: Adaptive Cruise Control and Autonomous Lane Keeping

1. **Adaptive Cruise Control**
   - 1.1 Problem Statement
   - 1.2 Technical Approach
   - 1.3 Hardware and Software Implementation
   - 1.4 Experimental Results
2. **Autonomous Lane Keeping**
   - 2.1 Problem Statement
   - 2.2 Technical Approach
   - 2.3 Hardware and Software Implementation
   - 2.4 Experimental Results
3. **Conclusions and Discussions**
   - 3.1 Conclusions (summary of results of different approaches)
   - 3.2 Discussions (comparisons and future improvements)

The technical report should contain actual experimental results rather than invented measurements.
